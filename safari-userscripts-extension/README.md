# X Remarks — Safari Userscripts 项目

[返回项目总览](../README.md) · [AI 开发约定](../AGENTS.md)

脚本入口：[`x-remarks.user.js`](x-remarks.user.js)。本目录为单文件用户脚本，不是 Chrome 扩展。

在 X(Twitter)的用户名下方显示你自己的本地备注,点一下就能改。
数据全部存在本机浏览器里,不上传、不联网、不需要注册。

- 时间线:**有备注的用户**,名字下方会多出一行小药丸(例如 `Base链研究`);没备注的用户什么都不显示,保持页面干净。
- 个人主页:有备注显示药丸,没备注显示 `＋ 备注` —— 这是**页面上的新增备注入口**。
- 内置示例备注（数量以脚本中的 `DEFAULT_REMARKS` 为准）,**只在首次运行时**写入本机,之后一切以你本机的数据为准。

## 一、先装 Userscripts

这是一个**用户脚本(userscript)**,不是独立 App,需要一个宿主来运行。iOS / iPadOS Safari 上用免费的 **Userscripts** 扩展。

1. App Store 搜索 **Userscripts**(图标是蓝底白色 `</>`,免费),安装。
2. 打开一次 Userscripts App,它会要求你**选择一个文件夹**存放脚本。
   - 建议在 iCloud Drive 里新建一个文件夹(例如 `iCloud Drive / Userscripts`)再选它,脚本本身能跟着 iCloud 在设备间同步(**注意:同步的是脚本代码,不是你的备注数据**,见第五节)。
   - 这一步必须做,否则后面无法添加脚本。
3. 在 Safari 里启用扩展:
   - **设置 → App → Safari → 扩展 → Userscripts → 打开**
   - 同一页里把网站权限给足:**所有网站 → 允许**(至少允许 `x.com`)。设成「询问」也能用,但每次进站都会弹窗。

> macOS Safari 流程一致:App Store 装 Userscripts → Safari 设置 → 扩展 → 勾选并给 x.com 权限。

## 二、放入脚本

**方法 A:在扩展面板里新建(推荐)**

1. Safari 打开 https://x.com
2. 点地址栏左侧的 **ᯤ / 扩展图标 → Userscripts**
3. 右上角 **+ → New Userscript**,把 `x-remarks.user.js` 的**全部内容**粘贴进去,覆盖掉模板
4. **Save**

**方法 B:把文件放进文件夹**

用「文件」App 把 `x-remarks.user.js` 拷进第一步选定的文件夹,Userscripts 会自动识别。

**确认装好了:** 回到 x.com 刷新,右下角出现一个半透明的 **⚙** 悬浮按钮 —— 看到它就说明脚本在跑。

脚本匹配 `x.com` / `twitter.com` / `mobile.twitter.com`,在 `document-idle` 后启动,等页面主区域出现才渲染,所以刚打开时药丸可能晚半秒才冒出来,正常。

## 三、日常使用

| 想做什么 | 怎么做 |
|---|---|
| 看备注 | 刷时间线即可,自动显示 |
| 改备注 | 点药丸 → 输入框改完 → **保存**(或直接按回车) |
| 删备注 | 点药丸 → **删除**;或把输入框清空后保存,效果相同 |
| **给新用户加备注** | 点进他的**个人主页**,点名字下方的 `＋ 备注` |
| 批量增删改 / 备份 | 点右下角 **⚙** 打开设置面板,直接编辑 JSON |

### 关于「加备注」的入口

时间线上不会给没备注的用户显示 `＋ 备注`(那样每条推文都挂个按钮太吵)。所以给一个新用户加备注只有两条路:

1. 点进他的个人主页,点 `＋ 备注`;
2. ⚙ 面板里直接往 JSON 里加一行。

### 编辑弹窗

- **保存** / 回车 —— 写入并立即刷新页面上所有药丸,右下弹出 `已保存`
- **删除** —— 删掉这条,提示 `已删除备注`
- **取消**,或点弹窗外的灰色区域 —— 什么都不改
- 输入框内容为空时点保存 = 删除

### 设置面板(⚙)

面板里是一个可直接编辑的 JSON 文本框,顶部显示当前共有多少条备注(只统计 `@` 开头的键)。

- **保存导入** —— 把文本框里的 JSON 写回本机,立即生效,提示 `已导入 N 条备注`。
  JSON 有语法错误会提示 `JSON 格式有误` 并**保持原数据不动**,不用担心手滑写坏。
- **复制导出** —— 把文本框当前内容复制到剪贴板（未保存的编辑也会一起复制）。粘到备忘录里就是一份备份。
  某些情况下系统不给剪贴板权限,会退化成「已选中,请手动复制」,自己长按复制即可。
- **关闭** —— 关掉面板(点面板外的灰色区域也能关)。

> ⚠️ **保存导入是整体替换,不是合并。** 面板里的内容就是保存后的全部数据。想在备份基础上追加,先把备份粘进来,再在里面加行,然后保存 —— 别指望粘一条进去会自动并入原有的。

## 四、备注数据格式

key 保留 `@` 前缀,值是备注文字:

```json
{
  "@0xLuo": "Base链研究",
  "@example": "链上研究"
}
```

**规则:**

- key **必须带 `@`**,不带 `@` 的键会被忽略(不报错,但也不生效)
- 查找**不区分大小写**(`@ZachXBT` 也能匹配到 `@zachxbt`),写入时保留你输入的原样
- 备注文字建议十来个字以内、不用 emoji;药丸独占一行不挤压用户名,但过长仍会被容器截断
- 用户改了 handle,备注就对不上了 —— 需要你手动改 key

**给单条备注单独指定样式**(值写成对象):

```json
{
  "@example": {
    "note": "链上研究",
    "color": "#ff3b30",
    "fontSize": "12px",
    "borderRadius": "6px"
  }
}
```

**全局默认样式**(三个保留键,影响所有没单独指定样式的药丸):

```json
{
  "__style_bgColor": "#007aff",
  "__style_fontSize": "12px",
  "__style_borderRadius": "6px"
}
```

不写 `__style_bgColor` 时,药丸颜色跟随当前主题的强调色。另有 `__opt_*` 前缀预留给以后的开关,目前没有启用项。这些保留键都会出现在导出的 JSON 里,原样保留即可。

## 五、备份与换设备(重要,请务必看)

**你新增的备注只存在这台设备的 localStorage 里。** 它:

- ❌ **不会**回写进 `x-remarks.user.js` —— 用户脚本没有写自己源文件的权限
- ❌ **不随 iCloud 同步** —— iCloud 同步的是脚本代码,不是备注数据
- ❌ **Safari 清除网站数据 / 清历史记录会连它一起抹掉**
- ❌ `x.com` 和 `twitter.com` 是两个不同的站点,**各存各的**。在 x.com 加的备注,切到 twitter.com 看不到(平时固定走 x.com 就不用管这条)

所以攒了备注之后请定期:**⚙ → 复制导出 → 粘进备忘录或文件里存好**。

**换手机 / 重装 / 清过缓存之后恢复:**
装好脚本 → 打开 x.com → **⚙** → 全选文本框内容删掉 → 粘贴备份 → **保存导入**。

**关于修改脚本里的 `DEFAULT_REMARKS`:**
那份内置数据只在「本机还没有任何数据」时用一次。已经跑过一次的设备,改它完全无效。想让**新装的设备**开箱就带上最新备注,可以把导出的 JSON 粘回文件里的 `DEFAULT_REMARKS` 再分发 —— 这相当于更新「出厂数据」,对老设备依然不生效,老设备只能走导出/导入。

## 六、常见问题

**页面右下角没有 ⚙**
脚本没跑起来。依次检查:Safari 扩展里 Userscripts 是否已打开 → x.com 的权限是不是「允许」→ Userscripts 面板里这个脚本是否处于启用状态 → 刷新页面。

**某个用户明明写了备注却不显示**
八成是 key 的问题:确认带了 `@`、拼写和当前 handle 一致(大小写无所谓)。也可能对方改了 handle。⚙ 面板里搜一下就知道。

**药丸点不动 / 点了没反应**
先看按下时按钮有没有**变暗缩小**:
- 有变暗但没弹窗 → 刷新页面重试;仍不行说明弹窗被拦截,请反馈。
- 完全没反馈 → 说明点到了别的图层上,请反馈。

**从时间线点进主页再返回,药丸不见了**
SPA 路由切换后脚本会重绘,大约半秒到一秒。等一下或轻微滚动一下页面。持续不出现请反馈。

**滚很久之后药丸串到别人名下**
不应该发生(有专门的防串号处理)。若复现,请记下操作步骤反馈。

**页面顶部老有个「在 App 中打开」的横幅**
那是 Safari 自己画的原生横幅,不在网页里,脚本无法移除(已试过并确认不可行)。两个办法:
1. 点横幅最左边的 `×`,点掉之后基本不再出现;
2. 地址栏 **ᯤ → 请求桌面网站**(对 x.com 长期生效)。

**弹窗配色和 X 的主题不一致**
弹窗和药丸会自动跟随 X 的主题(浅色 / 暗淡 / 全黑,后两者都按暗色渲染),切换后立即生效。若没跟上,刷新页面。

**点输入框时整个页面被放大**
不会 —— 输入框字号固定 ≥16px 规避了 iOS 的自动缩放。如果你改过样式导致这个问题,把字号调回 16px 以上。

## 开发维护

### 代码结构

| 区块 | 职责 |
|---|---|
| `DEFAULT_REMARKS` | 内置备注数据,key 为 `@handle` |
| 存储层 | `loadStore` / `persist` / `getStyleFor` / `setNote`;`lcIndex` 做大小写不敏感查找 |
| 选项 | `getOpt` / `setOpt` 脚手架,当前无启用项,存储键 `__opt_*` |
| 主题 | `detectTheme` 读 `data-theme`,`applyTheme` 写 CSS 变量 |
| 事件 | `bindDelegation`(主点击入口)+ `bindDirect`(元素级兜底) |
| 渲染 | `addProfileNote` / `addNotesToTimeline` / `renderAll` / `rerender` |
| UI | `buildEditor` 编辑弹窗、`buildUI` 设置面板、`toast` |

### Safari 开发注意事项

1. **不要在 `touchstart` / `pointerdown` 上 `preventDefault()`**。iOS Safari 会取消整个点击手势,`click` 永远不产生。拦 X 的跳转只用 `stopPropagation()`。
2. **事件委托挂 `window`,不是 `document`**。X 的脚本先加载,它在 document 上的监听排在前面,一旦调用 `stopImmediatePropagation` 就收不到事件。症状:一开始能点,SPA 路由切换后突然失效。
3. **不要用 `window.prompt` / `alert`**。iOS Safari 会静默拦掉,既不显示也不报错。用自建 DOM 弹窗。
4. **不要把元素级监听作为唯一点击通路**。全局事件委托是主通路，`bindDirect` 仅作兜底。
5. **不要往用户名那一行插元素**。那是定宽 flex 行,会把名字挤成省略号。用 `findColumnSlot` 向上找纵向容器,让徽章独占一行。
6. **不要依赖 X 的 class 名**(混淆且常变)。只用 `data-testid`:时间线是 `User-Name`,个人主页是 `UserName`(注意有无连字符)。
7. **虚拟列表会复用节点**,同一个 User-Name 区块可能换成别的用户。靠 `badgeOwner` WeakMap 精确清理旧徽章,否则会串号。
8. **顶部 App 横幅无法用脚本移除,不要再尝试**。那是 Apple 原生 Smart App Banner,由 Safari 画成浏览器浮层、不在 DOM 里,`querySelector` 找不到它;移除 `<meta name="apple-itunes-app">` 也无效(Safari 只在解析原始 HTML 时读一次,之后 JS 改动一律不理,`@run-at document-start` 同样赶不上)。已实现过一版特征识别方案并确认失败、代码已删。用户侧的办法只有两个:点 banner 最左侧的 `×`(点掉后基本不再出现),或对 x.com 开「请求桌面网站」。
9. 输入框字号必须 ≥ 16px,否则 iOS 聚焦时会自动放大整个页面。

### 手动验证清单

- [ ] 时间线:有备注的用户显示药丸,独占一行,**不挤压用户名**
- [ ] 时间线滚动数屏后,药丸仍与用户对应(不串号)
- [ ] 点药丸弹出编辑框;保存 / 删除 / 取消 三个按钮都生效
- [ ] 个人主页:有备注显示药丸,无备注显示「＋ 备注」,**只有一个入口**
- [ ] SPA 导航(时间线 → 个人主页 → 返回)之后点击仍然有效
- [ ] X 切换浅色 / 暗色主题,弹窗与药丸配色跟随
- [ ] 设置面板:导出 JSON 完整,粘贴导入后立即生效
- [ ] 按钮按下有变暗缩小反馈 —— 用来判断触摸是否命中(手机无控制台时的主要诊断手段)

排查点击失效时,按这个顺序定位:按下**无**视觉反馈 → 被覆盖层挡住,查 z-index / 插入位置;有反馈但无弹窗 → 事件链被拦截或弹窗被拦,查第 1~3 条。

### 数据约定

- 备注 key 保留 `@` 前缀;查找大小写不敏感,写入保留原始大小写
- 内部保留键:`__opt_*`(选项,当前无启用项)、`__style_*`(全局样式)
- 单条备注可用对象形式覆盖样式:`{ note, color, fontSize, borderRadius }`
- 备注文字不含 emoji
- 药丸默认色走 `var(--xr-accent)` 跟随主题;单条 `color` 优先

### 更新脚本

用本目录最新的 `x-remarks.user.js` 覆盖 Userscripts 中的旧脚本，再刷新 X 页面；不要同时启用两份脚本。更新代码不会覆盖已有备注，修改内置数据后也需通过设置面板导入才能更新已有设备的数据。
